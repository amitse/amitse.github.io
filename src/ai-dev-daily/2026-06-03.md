## Highlights

A big week for AI-native development culture: Anthropic quietly published a detailed guide to running engineering organisations where Claude is a first-class team member. Meanwhile Firefox drew a clear policy line on AI-generated contributions, and the community shipped a flurry of small but pointed tools — from a unified SDK for running Claude/Codex/Gemini agents to a persistent memory index that survives context-window resets.

---

## Tools

### Circus Chief — Run Claude Code, Codex, and Gemini from Your Phone

A new open-source iOS/Android shell app lets you fire off Claude Code, OpenAI Codex, and Gemini coding agents directly from your phone. It bridges the gap between mobile access and heavyweight desktop agents, making it possible to review and trigger agentic coding tasks while away from your machine.

[Source →](https://github.com/ferrislucas/Circus-Chief) · *Published 2 June 2026 on Hacker News*

### Paseo — Open-Source Coding Agent Interface

Paseo is a "beautiful open-source coding agent interface" that acts as a front-end wrapper over multiple coding agents. Submitted as a Show HN on 2 June, it aims to give developers a cleaner, opinionated UI rather than relying on raw CLI tools.

[Source →](https://github.com/getpaseo/paseo) · *Published 2 June 2026 on Hacker News*

### LiteHarness — One SDK for Claude Agent, OpenAI Agent, Pi AI

LiteHarness provides a single SDK surface to run tasks across Claude, OpenAI, and Pi AI agents. The value proposition is portability: write an agent task once and route it to whichever backend performs best for that task type.

[Source →](https://github.com/LiteLLM-Labs/lite-harness) · *Published 3 June 2026 on Hacker News*

### Clor — Give Your Agent Claws

Clor is a new tool (clor.com) that extends coding agents with persistent system-level capabilities — the pitch is adding web browsing, terminal access, and file I/O as composable "claws" on top of any LLM agent.

[Source →](https://clor.com/) · *Published 2 June 2026 on Hacker News*

## Models & APIs

### Anthropic Expands Public Access to Claude Mythos

Anthropic opened broader API access to Claude Mythos, its latest model variant, bringing it out of limited preview. The model is positioned for long-context and research-heavy workloads. Govinfosecurity reported the announcement on 2 June, citing expanded quota tiers for enterprise accounts.

[Source →](https://www.govinfosecurity.com/anthropic-expands-public-access-to-claude-mythos) · *Published 2 June 2026*

### Anthropic Faces AI Spending Backlash Before IPO

Axios reported on 2 June that Anthropic is fielding investor pushback over compute spend as it prepares for an IPO. The article notes that enterprise customers are scrutinising per-token pricing more carefully, which may accelerate pressure on Anthropic to lower API costs — good news for developers on tight budgets.

[Source →](https://www.axios.com/2026/06/02/anthropic-ipo-ai-sticker-shock-spending) · *Published 2 June 2026*

## Frameworks & Research

### How to Evaluate Models for Production Coding Agents

Blaxel published a practical guide (2 June) on choosing and benchmarking LLMs for production coding-agent use cases. The post covers beyond-SWE-bench metrics: latency distributions, retry rates, and failure-mode taxonomy that matters more in real pipelines than aggregate benchmark scores.

[Source →](https://blaxel.ai/blog/llm-coding-benchmarks) · *Published 2 June 2026 on Hacker News*

### Project Brain — Persistent Memory Index for AI Coding

Project Brain is a lightweight system for maintaining a persistent semantic index of a codebase across Claude Code sessions. It stores embeddings and summaries so agents can re-orient quickly after a context reset, reducing the "explain the codebase again" tax.

[Source →](https://github.com/OoneBreath/claude-code-project-brain) · *Published 2 June 2026 on Hacker News*

### AgenticOS — Cryptographically Verifiable State-Transition Engine

A new GitHub project (Ghoti6098/AgenticOS) proposes using cryptographic state hashing to make AI agent decision chains auditable and reproducible. Still experimental, but represents a growing interest in agent accountability infrastructure.

[Source →](https://github.com/Ghoti0698/AgenticOS) · *Published 3 June 2026 on Hacker News*

## Community

### Anthropic: "Running an AI-Native Engineering Org"

Anthropic published a detailed blog post on how to structure an engineering team that treats Claude as a first-class collaborator. The post covers toolchain choices, code-review norms with AI-generated patches, and how to preserve institutional knowledge when agents are writing a significant portion of the codebase.

[Source →](https://claude.com/blog/running-an-ai-native-engineering-org) · *Published 3 June 2026 on Hacker News*

### Firefox Publishes Official AI Coding Policy

Mozilla released a formal AI coding policy for Firefox contributors, clarifying which AI-generated code is acceptable in the source tree and what disclosure is required. The policy draws a line between AI-assisted refactors and wholesale AI-generated features, requiring human review and attribution for the latter.

[Source →](https://firefox-source-docs.mozilla.org/contributing/ai-coding.html) · *Published 2 June 2026 on Hacker News*

### Google Quietly Buys Code from Play Store Developers to Train AI

404 Media and Neowin reported on 3 June that Google has been paying Android developers to license their app code for AI training data. The program is invitation-only and the payments are described as "modest," raising questions about the long-term market for human-authored code as training material.

[Source →](https://www.404media.co/google-is-quietly-buying-code-from-play-store-developers-to-train-ai/) · *Published 3 June 2026*
