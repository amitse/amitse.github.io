## Tools

### GitHub Copilot Agent Mode: Autonomous Multi-File Editing

Copilot's new Agent Mode can navigate and edit multiple files, run terminal commands, and self-correct based on test output — all without per-step prompting. It's rolling out gradually to all Copilot subscribers in VS Code. This is the biggest Copilot capability jump since it launched; the self-correction loop means it can actually iterate on failing tests rather than handing back a broken diff.

[Source →](https://github.blog/2026-06-02-copilot-agent-mode-multi-file/)

### Cursor 0.52: Smarter Context and MCP Improvements

Cursor 0.52 improves context window management and file retrieval, and tightens up MCP tool-calling with reduced latency for background agents. If you rely on Cursor's tab completion in large monorepos, the smarter file retrieval alone is worth the update.

[Source →](https://cursor.sh/changelog/0.52)

### Windsurf Launches "Flows" — Persistent Sessions Across Devices

Windsurf's new Flows feature lets an AI coding session persist and be picked up by a different device or team member, preserving full context. Early adopters say it measurably cuts the time new contributors spend getting up to speed on an existing codebase.

[Source →](https://windsurf.ai/blog/flows-persistent-sessions)

### Continue.dev v0.9: Ollama 0.6 and Improved RAG

Continue.dev v0.9 adds full compatibility with Ollama 0.6, revamps its RAG pipeline for code context retrieval, and ships a cleaner UI for managing local model providers. A solid upgrade for developers running private LLMs for code assistance.

[Source →](https://continue.dev/changelog/v0.9)

## Models

### Claude 4 Opus — 68.4% SWE-bench Verified, 400k Context

Anthropic's Claude 4 Opus sets a new top score on SWE-bench Verified (68.4%) and HumanEval, with a 400k token context window available immediately on the Anthropic API and Amazon Bedrock. The context length is particularly relevant for repo-level tasks where current models struggle to hold enough code in view.

[Source →](https://anthropic.com/news/claude-4-opus)

### Codestral 2.1 — 20% Price Cut and Better FIM

Mistral's Codestral 2.1 drops API pricing by 20%, improves fill-in-the-middle (FIM) quality for autocomplete, and adds support for 40+ programming languages. Weights are available openly; this makes Codestral a more compelling default for self-hosted autocomplete setups.

[Source →](https://mistral.ai/news/codestral-2-1/)

### Gemini 2.5 Flash Update — 35% Faster Tool Calling

Google DeepMind's June update to Gemini 2.5 Flash cuts tool-calling latency by 35% and promotes structured JSON output to a first-class API feature. For agents making many sequential tool calls, the latency reduction compounds quickly.

[Source →](https://deepmind.google/discover/blog/gemini-2-5-flash-update-june-2026)

### Llama 3.3 70B Instruct — Tuned for Agentic Workflows

Meta released Llama 3.3 70B Instruct with significant improvements to multi-step tool use and ReAct-style reasoning — the model is explicitly positioned for agentic coding pipelines. Weights are on Hugging Face; this is the one to benchmark if you're running open-weight agents.

[Source →](https://ai.meta.com/blog/llama-3-3-70b-instruct-release/)

## Frameworks

### OpenHands 0.28 — Parallel Agent Execution

OpenHands v0.28 lets multiple sub-agents run in parallel on different parts of a codebase, plus a Docker-based sandbox for safer code execution. Parallel execution is the key addition here: code review automation that previously ran serially can now run in a fraction of the time.

[Source →](https://github.com/All-Hands-AI/OpenHands/releases/tag/0.28)

### LangGraph 0.4 — Native Human-in-the-Loop Checkpoints

LangGraph 0.4 adds HITL checkpoints that let developers pause an agent graph mid-execution, inspect state, and resume — without rebuilding the run. First-class streaming for tool outputs is also included. This addresses one of the biggest complaints about production agentic systems: no ability to intervene gracefully.

[Source →](https://blog.langchain.dev/langgraph-0-4-human-in-the-loop/)

### CrewAI 0.80 — Enterprise RBAC and Audit Logs

CrewAI 0.80 ships role-based access control, detailed audit logging, and corporate SSO integration for teams deploying agent crews in production. The OSS core is unchanged, so existing projects aren't affected.

[Source →](https://crewai.com/blog/crewai-0-80-enterprise)

### AutoGen 0.5 — Declarative Agent Topology via YAML

Microsoft's AutoGen 0.5 lets you define multi-agent pipelines in YAML rather than Python scaffolding, and adds sandboxed code execution agents out of the box. Declarative config lowers the barrier to defining complex topologies without wrestling with Python boilerplate.

[Source →](https://microsoft.github.io/autogen/blog/autogen-0-5-release/)

### SWE-agent 2.0 Preview — Multi-Turn Tool Use and Web UI

The SWE-agent team previewed v2.0 with multi-turn tool use, improved repo-level understanding, and a new web UI for monitoring agent trajectories. Early benchmarks show a 12% improvement on SWE-bench over v1.

[Source →](https://swe-agent.com/blog/2-0-preview)
